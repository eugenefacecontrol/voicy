# Voicy

Бесплатная браузерная озвучка любого текста. Вставьте текст, выберите доступный на устройстве голос и нажмите **«Слушать»**.

**Открыть приложение:** [https://eugenefacecontrol.github.io/voicy/](https://eugenefacecontrol.github.io/voicy/)

## Как пользоваться

1. Вставьте текст в большое поле. Пустые строки разделяют его на логические разделы.
2. Выберите голос. Список голосов предоставляет браузер и операционная система, поэтому на разных устройствах он отличается.
3. При желании выберите шрифт и скорость: 1×, 2×, 3× или 4×.
4. Нажмите **«Слушать»**. Та же кнопка ставит чтение на паузу и продолжает его.
5. Кнопки со стрелками перематывают чтение примерно на 10 секунд назад или вперёд. Две маленькие кнопки справа от них сразу переходят к предыдущему или следующему разделу.
6. Нажмите на количество разделов под текстом, чтобы открыть оглавление. Каждый раздел показывает примерный таймкод и запускает чтение с выбранного места.
7. Плавающая кнопка **«Разделы»** остаётся на экране во время прокрутки и открывает то же оглавление из любого места текста.
8. Плавающая кнопка **«Настройки»** прокручивает длинный текст прямо к выбору голоса и скорости и исчезает возле самого блока настроек.
9. Кнопка **«Стоп»** полностью останавливает воспроизведение.

Кнопка **«Вставить текст»** берёт текст из буфера обмена. Если браузер запретил доступ к буферу, кликните в поле и используйте `⌘V` или `Ctrl+V`.

Кнопка **«Читать»** скрывает поле ввода и показывает текст как обычную страницу — мобильная клавиатура в этом режиме не открывается. После вставки Voicy включает режим чтения автоматически. Чтобы изменить текст, нажмите **«Редактировать»**. Переход по таймкоду подсвечивает выбранный раздел и прокручивает страницу к нему.

Текст, выбранные настройки и текущая позиция чтения сохраняются только в локальном хранилище браузера. После обновления или повторного открытия страницы кнопка **«Слушать»** продолжит с сохранённого таймкода. Если изменить текст, старая позиция автоматически сбросится.

## Голоса Fish Audio

Выбор голоса объединён в одно меню с поиском по имени и языку:

- **Голоса устройства** работают через Web Speech API и не используют внешний TTS.
- **Fish Audio · Free API** загружаются только после успешной проверки API-доступа. Поиск обращается к публичному каталогу Fish Audio, включая русскоязычные модели сообщества.

Выбранный голос, язык и источник сохраняются в локальном хранилище. После перезагрузки Voicy восстанавливает даже Fish‑голос, который не попал в первые результаты каталога.

Для Fish используется только бесплатная модель `s2.1-pro-free`. Обычный баланс аккаунта может оставаться нулевым: модель имеет цену `$0` и работает в рамках Fish Audio Fair Use. Платные модели Voicy не вызывает.

При выборе Fish‑голоса текст отправляется фрагментами через Cloudflare Worker в Fish Audio, возвращается как MP3 и воспроизводится браузером. Пока звучит текущий фрагмент, Voicy параллельно генерирует до четырёх следующих и держит скользящий локальный кэш до семи фрагментов. Один и тот же аудиоплеер переиспользуется между фрагментами, поэтому после первого запуска воспроизведение продолжается автоматически. Скорости 1×–4×, пауза, продолжение, разделы и сохранение позиции продолжают работать. В оглавлении текущий раздел подчёркнут и автоматически прокручивается в центр списка. Публичные модели с именами известных людей созданы пользователями Fish Audio и не обозначаются Voicy как официальные или одобренные этими людьми.

На 10 августа 2026 года Fish Audio заявляет для `s2.1-pro-free` отсутствие жёсткого лимита символов в рамках Fair Use. Это временный экспериментальный доступ без SLA и гарантии скорости; текущая опубликованная дата окончания бесплатного периода — 31 августа 2026 года. Для Starter‑аккаунта общий лимит — до пяти одновременных API‑запросов, тогда как Voicy делает только один фоновый запрос следующего фрагмента.

## Как поделиться текстом

Кнопка **«Поделиться»** предлагает два варианта:

- **Короткая ссылка** — текст сначала сжимается и шифруется в браузере, а зашифрованный пакет хранится 30 дней в Cloudflare KV. Ключ расшифровки находится после `#` в ссылке и не отправляется в Worker. Получатель открывает ссылку на GitHub Pages, и браузер сам загружает, расшифровывает и показывает текст.
- **Ссылка без сервера** — сжатый текст целиком находится после `#` в URL. Никакое хранилище не используется, но вариант подходит только для небольших текстов: Voicy ограничивает такую ссылку 8000 символами.

На телефоне Voicy открывает системное меню **«Поделиться»**. Если оно недоступно, ссылка копируется в буфер обмена.

## Как это работает

Основное приложение остаётся статическим сайтом: GitHub Pages раздаёт HTML, CSS и JavaScript, а озвучивание выполняет встроенный браузерный [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API). Длинный текст автоматически делится на небольшие фрагменты и читается последовательно. Пустые строки считаются границами разделов, а плеер показывает текущий раздел и общий прогресс.

Перед озвучиванием Voicy удаляет служебные обратные слеши, их Unicode-варианты, HTML-записи и символы кавычек. Например, `\"цитата\"` произносится просто как «цитата». Исходный текст в редакторе при этом не изменяется.

Обычное использование системного голоса и вариант «Ссылка без сервера» не отправляют текст в наше хранилище. При создании короткой ссылки отдельный Cloudflare Worker получает только зашифрованный пакет; открытый текст и ключ остаются в браузере. При явном выборе Fish‑голоса текущий фрагмент текста проходит через Worker в Fish Audio для генерации аудио. Секретный API‑ключ хранится только в Cloudflare Worker Secret и никогда не попадает в GitHub Pages.

## Ограничения

- Лучше всего приложение работает в актуальных Chrome, Edge и Safari.
- Набор языков и качество голосов зависят от устройства и установленных системных голосов.
- В Firefox поддержка синтеза речи зависит от версии и настроек браузера.
- При закрытии вкладки воспроизведение прекращается.

## Локальный запуск

Сборка и зависимости не нужны. Можно открыть `index.html` напрямую или запустить простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте [http://localhost:8000](http://localhost:8000).

## Публикация

GitHub Pages уже настроен на публикацию содержимого корня ветки `main`. После каждого push сайт автоматически обновляется по адресу [https://eugenefacecontrol.github.io/voicy/](https://eugenefacecontrol.github.io/voicy/). Сборка не требуется.

## Cloudflare Worker и KV

GitHub Pages остаётся хостингом интерфейса. Cloudflare используется только как маленький API для зашифрованных коротких ссылок.

Первоначальное развёртывание:

```bash
npx wrangler login
npx wrangler kv namespace create VOICY_SHARES
```

Добавьте выданный `id` в `wrangler.jsonc`:

```json
"kv_namespaces": [
  { "binding": "VOICY_SHARES", "id": "полученный-id" }
]
```

Затем опубликуйте Worker:

```bash
npx wrangler deploy
```

Worker опубликован по адресу [https://voicy-share.eugenefacecontrol.workers.dev](https://voicy-share.eugenefacecontrol.workers.dev) и записан в `index.html` в метатег `voicy-share-api`. Код API находится в `worker/index.js`; записи автоматически удаляются через 30 дней.
